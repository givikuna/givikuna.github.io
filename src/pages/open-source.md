# open source contributions

overview of my open source contributions:

## upstream contributions

- **[devenv](https://github.com/cachix/devenv/)** - devbox containerization and deployment tool based on Nix, written in Rust.
- **[nixpkgs](https://github/nixos/nixpkgs/)** - the main package repository for the NixOS operating system, and the world's largest package repository.

## maintained projects

- **[loid](https://github.com/Loid-Project/loid/)** - multi-paradigm transpiled programming language with first-class types, functions, and classes.
- **[ysyldur](https://github.com/givikuna/ysyldur/)** - declarative linux kernel management flake for NixOS.
- **[ynternals](https://github.com/givikuna/ynternals)** - symmetric-key encryption system for secrets for NixOS computers.
- **[gitboy](https://github.com/givikuna/gitboy)** - declarative git repository management NixOS.
- **[nixtants](https://github.com/givikuna/nixtants)** - free-form constants namespace management flake for Nix.
